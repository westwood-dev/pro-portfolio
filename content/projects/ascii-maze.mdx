## A procedurally generated 3D maze

A first-person maze you play in the browser. The layout is never the same twice: it's generated with a recursive backtracking algorithm in 2D, then extruded into walls for the 3D space. Start and end stay fixed — everything between them is regenerated each time.

![Maze](/images/ascii-maze/maze.png)

![Start screen](/images/ascii-maze/start.png)

Built with Babylon.js, it was an exercise in generative geometry and turning a classic algorithm into something you can actually walk around inside.

[Live version](https://maze.williamwestwood.com/) | [Code on GitHub](https://github.com/iwouldntbother/ASCIIMaze)
